# Первый перенос клубного архива

На локальный Drupal перенесены пять публикаций о MA Cigar Fest 2016 и пять архивных дегустационных материалов. Из них собраны 35 связанных записей. Выпуск фестиваля ведёт к трём дням программы. Страницы сигар объединяют дегустации разных лет и городов. Полный текст каждого исходного материала хранится в журнале в одном экземпляре.

| Что открыть на стенде | Что проверить |
|---|---|
| [MA Cigar Fest 2016](http://localhost:8093/festival/2016) | Программа 14–16 октября и события по дням |
| [Русский вечер](http://localhost:8093/journal/ma-cigar-fest-2016-russian-evening) и [альбом](http://localhost:8093/albums/ma-cigar-fest-2016-day-1) | Порядок текста, подписей и фотографий |
| [Ramón Allones Specially Selected](http://localhost:8093/cigars/ramon-allones-specially-selected) | Две дегустационные карты, Москва — 95 и Екатеринбург — 89 |
| [Romeo y Julieta Wide Churchills](http://localhost:8093/cigars/romeo-y-julieta-wide-churchills) | Две встречи, 87 баллов в 2010 году и 90 в 2011-м |
| [Журнал о трёх витолах Macanudo](http://localhost:8093/journal/tri-vitoly-macanudo-1968) | Один исходный отчёт и три самостоятельные дегустационные карты |

## Состав и редакционные решения

Перенесены один выпуск фестиваля, семь событий, три альбома, десять публикаций журнала, шесть сигар и восемь дегустационных карт. На стенде посетителям открыты 30 записей. В редакторском списке пять черновиков — предложение партнёрам, приглашение на фестиваль, репортаж о гала-ужине, альбом гала-ужина и отчёт о Wide Churchills 2011 года. В них есть исторические коммерческие упоминания либо фотографии, требующие отбора. Из текста приглашения удалён абзац с платёжными и контактными данными.

Дата публикации взята из заголовка архива, дата встречи или дегустации — из материала. Для Ramón Allones сохранена также исходная запись «95/89». У Coronado by la Flor 96 баллов поставил один дегустатор. Архивная таблица повторяла эти баллы в двух колонках, поэтому в Drupal заполнена индивидуальная оценка. Строка Cazadores содержала ссылку на другую сигару и исключена из переноса. Сопоставление семи строк старого рейтинга с первоисточниками сохранено в [таблице сверки](../scripts/archive/pilot-evidence.json). До загрузки остальных материалов новый рейтинг отражает только имеющиеся в Drupal карты.

Из архива получено 569 оригинальных изображений, включая миниатюры, и два PDF. Оба документа приложены к закрытому черновику. Для 78 файлов старый сервер вернул HTTP 404.

| Исходная публикация | Что нужно найти в резервной копии |
|---|---|
| Гала-ужин, № 888 | 75 фотографий |
| Wide Churchills 2011, № 298 | Одна фотография |
| Приглашение, № 883 | Русская и английская версии приглашения в PDF |

Точные исходные адреса перечислены в поле `missing` [реестра файлов](../scripts/archive/pilot-inventory.json). В тексте отмечены места пропусков. При восстановлении из резервной копии редактор сможет вставить оригиналы на эти места. Повторный импорт пропускает существующие записи, сохраняя редакторские изменения.

Для опубликованных материалов зарегистрировано 12 точных переходов HTTP 301, в том числе варианты старой ссылки на выпуск фестиваля. Общие адреса старого рейтинга и всего списка дегустаций остаются за пределами этой партии. Черновикам не назначены публичные перенаправления.

## Воспроизведение

Приватный снимок на машине разработки находится в `~/.local/share/cigar-moscow/pilot-2016/snapshot`, дамп MySQL перед импортом — в соседнем каталоге `backups/before-import.sql.gz`. В `originals/` лежат исходные страницы, включая исторические персональные данные. Доступ к снимку ограничен владельцем. В Git хранятся правила сопоставления, идентификаторы и контрольные суммы. Для проверки уже сохранённого снимка достаточно следующих команд из корня проекта.

```sh
snapshot="$HOME/.local/share/cigar-moscow/pilot-2016/snapshot"
python3 -m venv /tmp/ma-archive-venv
/tmp/ma-archive-venv/bin/pip install beautifulsoup4==4.14.3 html5lib==1.1
/tmp/ma-archive-venv/bin/python tests/archive_fetch.py "$snapshot"
python3 scripts/archive/verify_sources.py "$snapshot"
```

Для новой выгрузки со старого домена запустите `/tmp/ma-archive-venv/bin/python scripts/archive/fetch.py КАТАЛОГ`. Дайте выгрузке отдельный закрытый каталог. Импорт проверяет контрольные суммы текстов и принимает только известные пропуски.

Поднимите локальный стенд через `scripts/local`. На существующем стенде с более ранней конфигурацией предварительно сохраните БД и файлы, затем примените `docker compose exec -T web vendor/bin/drush cim -y`. В Drupal передаются очищенные статьи, вложения и реестры. Исходный HTML остаётся в приватном снимке.

```sh
docker compose exec -T web install -d -m 0700 /opt/drupal/private/archive-pilot
COPYFILE_DISABLE=1 tar --no-xattrs -C "$snapshot" -cf - \
  articles assets attachments assets.json attachments.json extraction-report.json legacy-urls.json \
  | docker compose exec -T web tar xf - -C /opt/drupal/private/archive-pilot
docker compose exec -T web php -d memory_limit=512M vendor/drush/drush/drush.php \
  php:script /opt/drupal/scripts/archive/import.php
docker compose exec -T web php -d memory_limit=512M vendor/drush/drush/drush.php \
  php:script /opt/drupal/tests/archive_import.php
docker compose exec -T web vendor/bin/drush simple-sitemap:rebuild-queue
docker compose exec -T web vendor/bin/drush simple-sitemap:generate
```

На чистом стенде импорт создаёт 35 записей, повторный запуск находит все 35 по исходным идентификаторам. Проверка сравнивает текст и порядок фотографий с источниками, сверяет файлы по SHA-256 и проверяет связи, оценки, адреса и статусы публикации.
