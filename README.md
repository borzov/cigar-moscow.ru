# Московские Афисионадо

Сайт клуба на Drupal 11, Twig и MySQL. Рабочая версия рассчитана на локальную проверку редакторских сценариев и последующую интеграцию дизайна. Для запуска нужны Docker с Compose и OpenSSL.

## Локальный запуск

```sh
./scripts/local
```

Откройте [главную](http://localhost:8093/). При первом запуске скрипт создаёт локальные секреты, устанавливает зафиксированные в Composer версии пакетов, импортирует конфигурацию Drupal и загружает учебные материалы. Повторный запуск использует существующую БД. Переменная `CLUB_PORT` меняет локальный порт. MySQL доступен только внутри сети Compose.

Для остановки используйте `docker compose stop`, для продолжения — `docker compose start`. База, зависимости, ядро Drupal, фотографии и закрытые файлы расположены в томах. Сохраните локальный `.env` вместе с резервной копией. Docker Desktop может потребовать разрешить доступ к каталогу проекта.

## Вход редакции

Адрес входа — [учётная запись](http://localhost:8093/user/login), локальный администратор — `club-admin`. Команда для копирования пароля в буфер на macOS приведена ниже.

```sh
docker compose exec -T web cat private/local-admin-password | pbcopy
```

При первом входе подключите приложение-аутентификатор, подтвердите текущий пароль и введите код с экрана настройки. Для первичной привязки выделен один вход по паролю. Последующие входы требуют TOTP. Именные учётные записи сотрудников создаёт администратор в разделе «Пользователи».

| Роль | Работа в Drupal |
|---|---|
| Автор клуба | Создаёт материалы и фотографии, редактирует свои черновики |
| Редактор клуба | Проверяет, публикует и архивирует материалы, редактирует словари, ведёт переводы |
| Организатор клуба | Видит заявки в разделе «Содержимое → Заявки клуба» |
| Администратор | Настраивает сайт, права и меню |

## Что проверить на стенде

1. На [карточке учебной сигары](http://localhost:8093/cigars/demo-edition) откройте прокур, затем встречу и связанный альбом. В [рейтинге](http://localhost:8093/rating) показаны коллективные оценки с переходом к источнику.
2. В [разделе фестиваля](http://localhost:8093/festival) сравните будущий и архивный выпуски. Измените дату начала показа анонса, чтобы проверить две версии главной. Календарь и регистрация учитывают московскую дату.
3. В [журнале](http://localhost:8093/journal) откройте рубрику и перейдите к карточке сигары из статьи. Проверьте [подборку пар](http://localhost:8093/cigars/pairings) и [фотоальбомы](http://localhost:8093/gallery).
4. Переключитесь между русской и английской версиями [страницы клуба](http://localhost:8093/club) и [контактов](http://localhost:8093/contacts). В шапке остальных материалов EN ведёт на английскую витрину клуба.
5. Отправьте [заявку](http://localhost:8093/membership) с вымышленными именем и почтой. Откройте [закрытый список](http://localhost:8093/admin/content/club-applications) под учётной записью организатора или администратора. Сайт хранит версию согласия, дату и назначение обращения. Планировщик Drupal очищает записи через 90 дней.

Основное содержимое редактируется в [административном списке](http://localhost:8093/admin/content). Меню шапки и подвала доступны в [управлении меню](http://localhost:8093/admin/structure/menu). Для смены обложки отредактируйте материал по адресу `/home-cover`. Учебные даты будущего фестиваля рассчитываются от дня первичной установки. Владелец сайта заполняет сведения о партнёрах, составе президиума и контактах редакции.

## Работа с кодом и дизайном

- `config/sync/` — эталонная конфигурация Drupal. Здесь типы материалов, поля, словари, роли, редакционный процесс, текстовые форматы, шаблоны URL и настройки вывода. После согласованной настройки в интерфейсе выполните `docker compose exec web vendor/bin/drush cex -y` и проверьте изменения YAML.
- `web/themes/custom/aficionados/` — публичная тема. Каркас страницы находится в `templates/page.html.twig`, стили — в `css/site.css`. Drupal также принимает переопределения, например `templates/node--cigar.html.twig` и `templates/node--tasting.html.twig`.
- `web/modules/custom/club_public/templates/` — исходные шаблоны обложки, фотографии, сезонного блока и подборки. Дизайнер может скопировать нужный файл с тем же именем в `templates/` темы и работать там. Выбор публикаций и расчёт рейтинга выполняет модуль. После добавления шаблона выполните `docker compose exec web vendor/bin/drush cr`.
- `web/modules/custom/club_forms/` — публичные формы, регистрация на конкретный выпуск фестиваля, права доступа и очистка заявок.
- `scripts/fixtures.php` — учебное содержимое. Два изображения использованы для проверки работы медиатеки. [Исходный клубный репортаж](https://www.cigar-moscow.ru/cigar_news.html?item_id=886)
- [Модель материалов и перенос](docs/content-model.md) описывает связи, идентификаторы и переход со старого сайта.

## Проверки

```sh
docker compose exec -T web composer validate --strict
docker compose exec -T web composer audit
docker compose exec -T web vendor/bin/drush config:status
docker compose exec -T web vendor/bin/drush php:script /opt/drupal/tests/configuration.php
docker compose exec -T web vendor/bin/drush php:script /opt/drupal/tests/model.php
docker compose exec -T web vendor/bin/drush php:script /opt/drupal/tests/public.php
python3 tests/public_http.py
```

Функциональные тесты форм находятся в `web/modules/custom/club_forms/tests`. Для отдельной тестовой копии установите соответствующую ядру версию `drupal/core-dev` через Composer. Задайте `SIMPLETEST_BASE_URL`, `SIMPLETEST_DB` и доступный для записи `BROWSERTEST_OUTPUT_DIRECTORY`, затем выполните `vendor/bin/phpunit -c web/core web/modules/custom/club_forms/tests`.

## Размещение на shared-хостинге

Корень домена должен указывать на `web/`. Конфигурация, Composer, закрытые файлы и ключи находятся уровнем выше. Локальная среда использует PHP 8.5 и MySQL 8.4 с InnoDB. На выбранном тарифе сверьте расширения через `composer check-platform-reqs --no-dev`, права Drupal на каталог файлов, обработку фотографий, HTTPS и доступ к cron. Сборка зависимостей возможна до загрузки на хостинг.

Создайте вне публичного каталога `settings.host.php` с реквизитами MySQL в `$databases`, индивидуальным `$settings['hash_salt']` и точным списком `$settings['trusted_host_patterns']` для основного домена. Для PHP и cron задайте одинаковый `CLUB_TFA_KEY` — 32 случайных байта в Base64. Значение требуется сохранять при переносе существующих учётных записей с подключённым вторым фактором. Храните резервную копию ключа отдельно от дампа БД.

На рабочей площадке устанавливают зависимости из lock-файла, применяют БД и конфигурацию, настраивают боевую почту, создают редакционные записи и периодически запускают `vendor/bin/drush --uri=https://www.cigar-moscow.ru cron`. Тот же основной адрес используйте при генерации Sitemap. Для чистой установки из YAML используйте `drush site:install --existing-config`, затем `drush config:import`; установку выполняют на пустой базе. Для обновления существующей установки — резервная копия, `drush updatedb`, `drush config:import` и `drush cr`. Команда `scripts/local` предназначена для локального стенда с примерами.

Резервная копия включает дамп MySQL, содержимое каталогов публичных и закрытых файлов, версию кода и конфигурации. Восстановление проверяют на отдельной базе вместе с открытием фотографий и входом сотрудника через TOTP.

Перед открытием форм укажите оператора ПД, действующие контакты, порядок отзыва согласия и утверждённый текст на `/privacy`. При смене редакции согласия обновите `ApplicationForm::CONSENT_VERSION`. Производственный адрес, тариф и параметры исходящей почты определяет клуб.
